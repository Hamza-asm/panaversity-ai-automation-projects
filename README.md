A collection of four AI-assisted Python scripts developed for the Panaversity assignment. This repository demonstrates a "client, not coder" approach to solving everyday data problems, including financial transaction analysis, custom grade calculation, payment reconciliation, and automated file organization.

## Repository Overview

Each task focuses on a practical automation problem and uses Python to turn messy input into a clear, usable result.

## Task Folders

| Folder | Description |
| --- | --- |
| [Task_01_MoneyDetective](Task_01_MoneyDetective) | Analyzes bank transactions to find recurring charges, possible forgotten subscriptions, and duplicate or suspicious payments. |
| [Task_02_WhatsMyGrade](Task_02_WhatsMyGrade) | Calculates the current class grade from weighted scores and tells how much is needed on the final exam to get an A. |
| [Task_03_TheBooksDontMatch](Task_03_TheBooksDontMatch) | Reconciles a messy payment log against an expected tour target and identifies who still owes money. |
| [Task_04_OrganizeTheMess](Task_04_OrganizeTheMess) | Scans a folder, flags large files, finds duplicates, and organizes files by type after a dry run and approval step. |

## What This Repo Demonstrates

- Rule-based data cleaning and analysis
- Safe execution with dry-run approval before destructive actions
- Practical use of Python standard libraries and Pandas
- Turning unstructured or messy data into clear reports
