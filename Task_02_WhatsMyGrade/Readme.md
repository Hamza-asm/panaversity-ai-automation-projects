# Whats My Grade

Whats My Grade is a Python project that calculates the current class standing from raw scores and grading weights. It also tells the student exactly how many marks are needed on the final exam to get an A.

## Tech Stack

- Python 3
- Basic arithmetic and control flow
- No external libraries required

## How It Works

The script takes quiz, assignment, and midterm scores, applies the teacher's grading policy, calculates the current percentage, and maps that percentage to a letter grade. It also computes the exact final-exam score needed for an A using the class weight rules.
